# 28: Complete product validation and production rollout

**What to build:** Evidence from sustained personal use that FilaManager remains aligned with physical inventory, followed by a deliberate production release only if the MVP meets its product and platform gates.

**Blocked by:** 27: Qualify the Play-delivered MVP.

**Status:** ready-for-agent

- [ ] The Play-delivered build is used as the real inventory for four weeks, with discrepancies and the recovery action used to resolve each one recorded.
- [ ] During validation, the hobbyist can find any filament spool's location, state, and remaining quantity within ten seconds.
- [ ] Storage-slot scanning remains faster than manual lookup when platform conditions permit it, while every workflow remains usable without NFC.
- [ ] No validation case loses history, creates ambiguous occupancy, silently changes inventory, or requires a permanent deletion to recover.
- [ ] Any defect that invalidates the product criteria or release disclosures is fixed and the affected qualification is repeated before rollout.
- [ ] Target API rules, Play policy deadlines, account tasks, disclosures, privacy policy, App Link association, support details, price, countries, and Console warnings receive one final current-state review.
- [ ] Production is released through managed publishing only after the validation and release gates pass, with the final version and evidence retained for future maintenance.
